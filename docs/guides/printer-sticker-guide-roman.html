Printer aur sticker guide

Mobile Shop software ke liye: kaunsa sticker, kaunsa kaghaz, kaunsa printer lein · 16 November 2026

Mukhtasar jawab

  • Sticker: 60 × 40 mm (chaurai 60 mm, unchai 40 mm), direct thermal roll.
  • Raseed (chhota bill): 80 mm thermal roll.
  • Bara bill aur reports: A4 kaghaz.
  • Printer woh lein jis mein USB cable aur Wi-Fi / LAN dono hon.

1. Sticker (barcode label) ka size

Software mein sticker par 11 cheezen aa sakti hain: dukaan ka naam, model, storage · rang, qeemat, barcode, IMEI number, IMEI ke aakhri 4 hindse, condition, PTA, tareekh aur cost code. Neeche har size ka nateeja hai jab saari 11 cheezen tick hon.

  • Roll: 60 × 40 mm "direct thermal" label roll, stickers ke darmiyan gap wala, 1 column. Is mein ink ya ribbon nahi lagta.
  • Barcode: jitni kam cheezen tick hongi, barcode utna bara hoga (60 × 40 par 12 mm tak).
  • Apna size: software chaurai 20 se 110 mm aur unchai 10 se 110 mm tak leta hai.

Pehle test karein: ye naap screen par liye gaye hain, asal printer par nahi. Roll ka pura carton lene se pehle 5–10 sticker print karke apne scanner se scan zaroor karein.

3. Kahan se print hoga (cable, Wi-Fi, Bluetooth)

Software printer se seedha baat nahi karta. Print Windows ya Android ke apne print dialog se hota hai, is liye wohi printer chalega jo computer ya phone mein "printer" ke taur par install ho.

Mobile ke baare mein seedhi baat: sticker aur thermal raseed computer ya laptop se print karna sab se pakka hai. Mobile ya tablet se thermal sticker printer chalana aksar mushkil hota hai. A4 Wi-Fi printer mobile se chal jata hai.

Aise sticker printer Xprinter aur Zebra jaise brands mein, aur raseed printer Xprinter aur Epson jaise brands mein milte hain. Ye sirf brand ki misaalein hain; koi khaas model test nahi kiya gaya.

5. Khareedne se pehle dukandar se poochein

  • Kya is model mein USB aur Wi-Fi / LAN dono hain?
  • Kya is ka Windows driver milta hai? (Dukaan par laptop se ek test print karwa lein.)
  • Sticker printer: kya ye 60 × 40 mm gap wala roll leta hai?
  • Raseed printer: kya ye 80 mm ka hai (58 mm nahi) aur auto-cutter hai?
  • Agar printer kaam na kare to wapsi ya tabdeeli ho sakti hai?
