## Where the working documents are · Kaam ke docs kahan hain
These guides are written for reading. The project's living working docs stay in [`docs/`](../):
requirements (01, 02), architecture and data model (03, 04), roadmap and progress (05, 06), testing (07), session log (09), decisions/ADRs (10), design system (11), deployment (12), mobile app (13), manual test plan (14).

Ye guides parhne ke liye hain. Rozana ke kaam ke docs (requirements, progress, session log, ADRs, deployment) `docs/` mein hi hain aur wahin update hote hain.

## Keeping them current · Inhein naya rakhna
When a feature changes, update the matching guide in both languages in the same commit (CLAUDE.md: "stale docs are bugs").
Jab koi feature badle, dono zubanon wali guide usi commit mein update karein.
